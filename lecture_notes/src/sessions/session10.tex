\section{Machine learning and many-body physics in two directions}

Let us first give the plan of this session, since the session goes in two directions and it is
useful to know which direction we are following at each point. In one direction, we use
machine-learning architectures, mostly neural networks, to solve many-body problems. Examples are
to represent wavefunctions that are too large to store, to reconstruct states from a small number
of measurements, to classify phases of matter and to learn Hamiltonians from experimental
observables. In the other direction, we use many-body architectures, in particular tensor
networks, as machine-learning tools, and we apply them to ordinary tasks such as image
classification. Under both directions there is a third theme, which is probably the most important
one in practice. This is to combine machine learning with the condensed-matter methods that we
already have, such as density functional theory, phase classification and the extraction of
Hamiltonians, to solve problems that are hard for each of the two approaches alone. We will follow
the same order as the lecture. We start with neural networks and how they learn, then neural
network quantum states and tomography, then tensor networks used as machine learning, then machine
learning inside density functional theory, then phase classification, and at the end Hamiltonian
learning.

\section{Neural networks as function approximators}

Machine learning is a large field, and we should say clearly which part of it we use in this
session. There are three broad types of task. \textbf{Supervised learning} maps labeled inputs to
outputs, and the standard example is image classification. This is the type that we will use in
the rest of the session. \textbf{Generative learning} models a probability distribution directly,
so that one can \emph{sample} new instances from it. For instance, a generative adversarial network
that is trained on photographs of cats can produce realistic images of cats that never existed.
\textbf{Reinforcement learning} trains an agent to choose the actions that maximize a cumulative
reward, given the state of its environment. In this session we will not develop generative or
reinforcement learning further, even though both of them have real uses in other parts of quantum
materials. We keep the GAN example with cat faces in mind only to remember that supervised learning
is not the whole field, even if it is all that we use in this session.

We can think of a deep neural network as a very flexible function with parameters. It takes an
input, which is an array of numbers, passes it through a sequence of layers, and gives an output,
which is another array of numbers. Inside a layer, the value of each node is a nonlinear function
of the values of all the nodes in the previous layer, combined with a set of free parameters. These
parameters are the \emph{weights}, one for each connection, and the \emph{biases}, one for each
node. The architecture, which is the number and the width of the layers, fixes how complex a
function the network \emph{can} represent. The specific values of the weights and biases, which we
call together $\theta$, fix which function it \emph{does} represent at a given moment. To train a
network means to search over $\theta$ for the values that make the network give the function that
we want. In practice, we define a \textbf{loss function} $\mathcal{L}(\theta)$ that measures how
far the output of the network is from the desired one, and we minimize it. This is usually done
with backpropagation, which is an efficient and exact way to compute $\partial
\mathcal{L}/\partial\theta$ with the chain rule, together with gradient descent,

\begin{equation}
\mathcal{L}(\theta) = \sum_n \left\| f_\theta(x_n) - y_n \right\|^2, \qquad \theta \;\longrightarrow\; \theta - \eta\, \nabla_\theta \mathcal{L}(\theta),
\end{equation}

where $\{(x_n, y_n)\}$ is a set of labeled training examples and $\eta$ is the learning rate. Every
use of a neural network in this session is a variation of (10.1), even when the physics attached to
it is exotic. We have to choose the right input, the right output and the right loss, and then the
training procedure is always the same gradient descent.

The concrete example that we keep in mind is the classification of images of cats and dogs, since
we will use the same architecture two more times in this session. An image is an $N\times N$
matrix of pixel values. We flatten it into the input layer of the network, and the output layer has
only two nodes, with the target $(1,0)$ for ``cat'' and $(0,1)$ for ``dog.'' We train on a labeled
set of images by minimizing (10.1), with $f_\theta$ the output of the network and $y_n$ the one-hot
label. Once the network is trained, it classifies new images that have no label. This template can
be used in many cases, since nothing in it depends on the input being a photograph. It only needs
the input to be an array of numbers with a categorical label. We will see the same structure, an
input matrix and a one-hot output, again in Section 10.6, where a spin configuration takes the place
of the photograph. Figure~\ref{fig:s10:template} shows the template once, and the four later
constructions of this session use it without change except for the choice of input, output and
loss.

\section{Neural network quantum states}

In this section we meet neural network quantum states (NNQS) for the first time in the course, and
we treat them directly with the machine-learning methods of Section 10.2. The idea in one sentence
is that a neural network can take the place of the exponentially many coefficients of a many-body
wavefunction. In this way it has its own place in the hierarchy of variational many-body states
that this course has been building since the matrix product states of session 7. In this section
we make this idea precise. We will see what the network computes, which loss function is used to
train it, and how it is related to the ans\"atze that we already know.

We start from a difficulty that we have met before, most recently in the discussion of
entanglement growth in session 7. A wavefunction for $L$ spins,

\begin{equation}
|\psi\rangle = \sum_{s_1,\dots,s_L} C(s_1,\dots,s_L)\, |s_1,\dots,s_L\rangle,
\end{equation}

is given by $2^L$ coefficients, and it is not possible to store them explicitly once $L$ is much
bigger than 30 or 40. The idea of a neural network quantum state (NNQS) is to not store
$C(s_1,\dots,s_L)$, and instead to \emph{generate} it. We build a neural network $C_\theta$ that
takes a spin configuration $(s_1,\dots,s_L)$ as input, which is formally an $L$-pixel ``image,''
and returns the coefficient. For a wavefunction that is complex, it returns its real and imaginary
parts as two output numbers, or in an equivalent way its modulus and phase. This is the same idea as
the matrix product state of Section 10.4 below, where a compact generator takes the place of
exponentially many numbers, but here it is built from the parameters of a neural network and not
from a chain of matrices.

The question is then how to find the right $\theta$ for the ground state, and here the methods of
Section 10.2 appear again with almost no change. The variational principle tells us that

\begin{equation}
E[\theta] \;=\; \frac{\langle \psi_\theta | H | \psi_\theta\rangle}{\langle \psi_\theta|\psi_\theta\rangle} \;=\; \frac{\sum_{s,s'} C_\theta^*(s)\, H_{s s'}\, C_\theta(s')}{\sum_s |C_\theta(s)|^2} \;\geq\; E_0,
\end{equation}

where the equality holds only when $|\psi_\theta\rangle$ is the true ground state, or in practice
the closest state that the ansatz can reach. Equation (10.3) \emph{is} the loss function of (10.1),
meaning that the ``observable output'' that the network is trained to minimize is the energy of
the system. To compute (10.3) without a sum over all the $2^L$ configurations, one samples $s$ from
the Born distribution $p(s) = |C_\theta(s)|^2/\sum_{s'}|C_\theta(s')|^2$ and evaluates the energy
as an average of the sampled local energy,

\begin{equation}
E_{\rm loc}(s) = \sum_{s'} H_{s s'}\, \frac{C_\theta(s')}{C_\theta(s)}, \qquad E[\theta] = \big\langle E_{\rm loc}(s)\big\rangle_{s\sim p},
\end{equation}

which only needs $H$ between the configurations that are connected by the Hamiltonian, which is
usually sparse, and not the full $2^L\times 2^L$ matrix. The training is then done in the same way
as in (10.1). We compute the energy and its gradient with respect to the parameters of the network,

\begin{equation}
\frac{\partial E}{\partial \theta_k} = 2\,\mathrm{Re}\Big[\big\langle E_{\rm loc}(s)\, O_k^*(s)\big\rangle - \big\langle E_{\rm loc}(s)\big\rangle\big\langle O_k^*(s)\big\rangle\Big], \qquad O_k(s) \equiv \frac{\partial \ln C_\theta(s)}{\partial \theta_k},
\end{equation}

and we update $\theta_k \to \theta_k - \eta\, \partial E/\partial\theta_k$ many times, with a
learning rate $\eta$ as in any other training of a neural network, until the gradient vanishes and
the energy has converged to its variational minimum.

We should now say clearly how NNQS is related to the other variational ans\"atze of this course.
The slides show this as a set of nested regions. The full many-body Hilbert space is one region,
and inside it there is a smaller region with all the states that an NNQS with a given architecture
can reach. Projected entangled pair states are inside this NNQS region, and matrix product states,
which we built in session 7, are inside the PEPS region. The parameterizations of gapped
one-dimensional systems are in the innermost region, since a matrix product state is a particular
and highly structured choice of ``network.'' NNQS is therefore the most expressive of the
variational families of this course, because it imposes the least structure on how the
coefficients depend on the configuration. Equation (10.3) is the loss function, and (10.4)-(10.5)
are the training procedure, and together they make this picture a working method and not only a
structure. Figure~\ref{fig:s10:nnqs} shows all three parts, which are what the network computes,
how the sampled estimate of the energy is built, and the nested picture.

\subsection{Quantum state tomography}

A second and different use of the same NNQS ansatz is \textbf{quantum state tomography}. Let us
take a real experimental system in some unknown state $|\psi\rangle$, and let us say that the only
access that we have to it is through projective measurements. We measure the state of every spin,
and the system collapses to one configuration $s$ with probability $|C(s)|^2$. If we repeat the
measurement many times, we obtain a set of observed configurations that are distributed according
to $|C(s)|^2$. However, we never observe $C(s)$ itself but only its modulus squared, and to do
this for all the $2^L$ configurations one by one is the same exponential problem that we started
with.

The solution has the same structure as the ground-state search above. We parameterize the unknown
amplitude and phase with a network, for instance a restricted Boltzmann machine, or with two
separate networks, one for $|C_\theta(s)|$ and one for its phase. Then we fit $\theta$ by
\textbf{maximum likelihood} to the observed measurement outcomes, instead of minimizing an energy.
In practice, one maximizes $\sum_{s} n(s) \ln p_\theta(s)$ over $\theta$, where $n(s)$ counts how
many times the configuration $s$ was observed and $p_\theta(s) =
|C_\theta(s)|^2/\sum_{s'}|C_\theta(s')|^2$ is the probability predicted by the network. This
reconstructs a full approximation to the unknown wavefunction with far fewer than $2^L$
measurements, and this is what makes it useful as an experimental tool, since nobody can run a
tomography experiment that needs an exponential number of measurements.

This part comes from the slides and the transcript and has no notebook counterpart, in line with
the fact that this session has no companion notebook. There is no \texttt{sessionN.ipynb} cell to
point you to here, so (10.3)-(10.5) and the tomography likelihood above are the complete and
self-contained derivation.

\section{Tensor networks for machine learning and the many-body wavefunction as a big-data problem}

We now follow the logic of the previous section in the reverse direction. Instead of using a
machine-learning architecture to solve a many-body problem, we treat the many-body wavefunction
itself as a big-data problem, and we use a many-body compression technique, which is tensor
networks, as a machine-learning architecture.

Let us recall the matrix product state (MPS) ansatz, which we already know from session 7. Instead
of storing all the $2^L$ coefficients of (10.2) independently, we assume that they factorize into a
product of matrices, one for each site,

\begin{equation}
C(s_1,\dots,s_L) = \mathrm{Tr}\left[A^{s_1} A^{s_2}\cdots A^{s_L}\right],
\end{equation}

where for each physical value of $s_i$, for example spin up or spin down, there is a different
$D\times D$ matrix $A^{s_i}$, and $D$, which is called the \emph{bond dimension}, is a free
parameter that we choose. The number of free parameters in (10.6) scales as $L \times d \times
D^2$, with $d$ the dimension of the local Hilbert space, so it is linear in the system size and not
exponential. This is the same compression idea as the NNQS of Section 10.3, but the parameters are
matrix elements instead of network weights. The same compression can be generalized beyond the
one-dimensional geometry of the MPS. A \emph{tree tensor network} puts the same matrices in a tree
instead of a chain. The \emph{multiscale renormalization ansatz} (MERA) adds extra layers of
coarse-graining on top of a tree structure. \emph{Projected entangled pair states} (PEPS)
generalize the whole construction to a two-dimensional grid. For a ground-state search these
architectures are not equivalent, since an MPS is much easier to optimize than a PEPS, and this is
the reason why MPS works well for one-dimensional problems while two-dimensional problems are often
still hard. However, if we only want a flexible function of a high-dimensional input with an
efficient parameterization, as in machine learning, the difference between the architectures
matters much less, and any of them can be used.

This is a direct reuse of the architectures of session 7, and not only an analogy. The same matrix
product states, tree tensor networks, MERA and PEPS that we built there to compress ground-state
wavefunctions are used here without change as function approximators. This approach has a name,
which is ``quantum-many-body-inspired machine learning,'' and a clear example of it is image
classification with tensor networks. We map each pixel of an image with $N$ pixels to a
two-dimensional vector, for example white $\to$ spin up and black $\to$ some other reference
direction. Then we take the tensor product of all the $N$ pixel vectors and obtain a single vector
in a $2^N$-dimensional space, which is the same exponentially large space where a many-body
wavefunction with $N$ spins lives. The classification task then becomes the search for a
\emph{linear} operator on this $2^N$-dimensional space that maps each image to its one-hot label.
A tensor network, and here a tree tensor network works well, is the efficient and structured
parameterization of such a linear operator that (10.6) and its generalizations already gave us. We
apply the tensor network to the tensor-product image, and then a final small tensor that projects
down to two output numbers. This gives the same structure as the classification of cats and dogs in
Section 10.2, where now the worked example is ``purse versus shirt'' and the tensor product of the
pixels takes the place of the flattened input matrix. Figure~\ref{fig:s10:tnml} shows the four
geometries as tensor diagrams, and then the classifier built from one of them.

\input{figures/s10f03_tnml}

This is not a toy result. On the Fashion-MNIST dataset, which is a standard benchmark of images of
clothes, this tensor-network classifier reaches \textbf{95.38\% accuracy on the training set and
88.97\% on the test set}, which is comparable with conventional neural network architectures on
the same task. These numbers appear only on the slides, and in the recording they are only
described as ``very high accuracy.'' They are the kind of concrete result that we want to have in
the written notes and not leave implicit. The general point is the same as in Section 10.3, in the
other direction. A variational architecture that was built to compress many-body wavefunctions is,
in mathematical terms, one more kind of neural network, and we can use it directly as one.

\section{Machine learning in density functional theory}

We now turn to a different problem, and to a much older method of condensed matter, which is
density functional theory (DFT). The motivation is the same as in Section 10.3, but now for real
materials instead of lattice models. Let us take the Hamiltonian of a material,

\begin{equation*}
H = \sum_i \left(-\frac{\hbar^2\nabla_i^2}{2m}\right) + \sum_i v_{\rm ext}(\mathbf{r}_i) + \frac{1}{2}\sum_{i\neq j} \frac{e^2}{|\mathbf{r}_i - \mathbf{r}_j|},
\end{equation*}

with $v_{\rm ext}$ the potential of the nuclei. For a realistic number of electrons, it is not possible to obtain the many-body ground state $\psi_0(\mathbf{r}_1,\dots,\mathbf{r}_N)$ directly. DFT avoids this problem by asking a smaller question. It does not ask for the full wavefunction, but for the ground-state electronic density $n(\mathbf{r}) = N\int |\psi_0|^2\, d^3r_2\cdots d^3r_N$, which has a much lower dimension.

The \textbf{Hohenberg-Kohn theorem} is what makes this approach exact and not only convenient. For
a given external potential $v_{\rm ext}(\mathbf{r})$, the ground-state density $n(\mathbf{r})$
determines $v_{\rm ext}(\mathbf{r})$ uniquely, up to an additive constant, and therefore it
determines the full Hamiltonian and the full many-body wavefunction. The arrow $\psi_0 \to n$ is
trivial, since it is an integral. The arrow $n \to \psi_0$ is the nontrivial content of the
theorem, and the theorem says that this arrow is \emph{guaranteed to exist}. As a result, the
ground-state energy is a functional of the density alone,

\begin{equation}
E[n] = F[n] + \int d^3r\, v_{\rm ext}(\mathbf{r})\, n(\mathbf{r}),
\end{equation}

where $F[n] = T[n] + V_{ee}[n]$ is a \emph{universal} functional, meaning that it is the same for
every system and does not depend on $v_{\rm ext}$, and nobody knows its exact mathematical form.

The \textbf{Kohn-Sham construction} makes (10.7) useful in practice. We introduce a fictitious
system of non-interacting electrons, which is chosen so that it has the \emph{same} density
$n(\mathbf{r})$ as the real interacting system, and which is described by an effective
single-particle Hamiltonian

\begin{equation}
H_{\rm KS} = -\frac{\hbar^2\nabla^2}{2m} + v_{\rm eff}(\mathbf{r}), \qquad v_{\rm eff}(\mathbf{r}) = v_{\rm ext}(\mathbf{r}) + \underbrace{e^2\!\int\! d^3r'\, \frac{n(\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|}}_{\text{Hartree (mean-field) term}} + \underbrace{\frac{\delta E_{\rm xc}[n]}{\delta n(\mathbf{r})}}_{v_{\rm xc}(\mathbf{r})}.
\end{equation}

The first part of $v_{\rm eff}$ is the external potential of the nuclei. The second part, the
Hartree term, is a mean-field decoupling of the interaction, with the same structure as the
mean-field theory of session 1, but applied here to the Coulomb interaction instead of a Hubbard
term on a lattice. The last part, the exchange-correlation potential $v_{\rm xc}$, is defined so
that it contains everything that the mean-field approximation misses, and it is as unknown as
$F[n]$ was. In practice one uses an approximation for $E_{\rm xc}[n]$, such as LDA, GGA, meta-GGA
and further refinements, and solves (10.8) self-consistently. We start from a guess for the density,
build $H_{\rm KS}$ and diagonalize it to obtain the Kohn-Sham orbitals. Then we compute the density
again from these orbitals, and we repeat until convergence.

In the lecture we discussed two different places where machine learning can enter this loop. We
keep them separate, because they solve different problems.

\begin{itemize}
\item \textbf{Learning the functional itself.} We replace or improve the LDA, GGA or meta-GGA
  approximation to $E_{\rm xc}[n]$, or to its functional derivative $v_{\rm xc}$, with a neural
  network, which is trained to reproduce reference calculations with a higher accuracy. This can
  improve the accuracy, but it does \emph{not} remove the self-consistency loop. We still have to
  diagonalize $H_{\rm KS}$ at every iteration, and this remains the expensive step for large
  systems, independently of how good $v_{\rm xc}$ is.
\item \textbf{Learning the whole map.} A more ambitious use of the Hohenberg-Kohn theorem is to
  remove the self-consistency loop completely. We train a neural network to map the atomic
  positions, or equivalently $v_{\rm ext}(\mathbf{r})$, directly to the ground-state density
  $n(\mathbf{r})$, with no diagonalization at all when the network is used. This is the idea behind
  machine-learned density functionals, which are related to the machine learning interatomic
  potentials that map atomic positions to energies and forces, an established technique in quantum
  chemistry and condensed matter. We train the network on conventional Kohn-Sham calculations for small
  systems that we can solve, and then we apply it to much larger systems, where a direct Kohn-Sham
  calculation would be too expensive.
\end{itemize}

The Hohenberg-Kohn reduction is very asymmetric on purpose, since going from the many-body ground
state to the density is a $3N\to3$ integral that anyone can do, while going back is guaranteed to
be possible but has no formula, and this missing formula is where machine learning can enter.
Figure~\ref{fig:s10:dft} places both routes on the self-consistency loop, which is the fastest way
to see why only the second one changes which systems we can compute.

\section{Phase classification with local order parameters and topological order}

We now come to a section that is, in a real sense, a review of the classification scheme of the
whole course, seen from the point of view of machine learning. In this course we have used two
quite different tools to distinguish phases. Sessions 1, 5, and 6 used a \textbf{local order
parameter}, which is a quantity built from a simple local expectation value that is zero in one
phase and nonzero in the other. Examples are the charge imbalance for the CDW, the magnetization for
the magnet and the pairing amplitude for the superconductor. Sessions 3 and 4 instead used a
\textbf{topological invariant}, such as the Chern number or the Zak phase, because the phases there
are \emph{not} distinguished by any local quantity at all, and the difference can only be seen in
a non-local way. The phase-classification example of this session uses this contrast as an
``easy'' and a ``hard'' worked example of machine learning, and the lecture itself presents it in
this way.

\textbf{The easy case, the Ising model.} Let us take classical Ising spins $\sigma_i = \pm 1$ on a
square lattice, with the standard nearest-neighbor Hamiltonian and a local order parameter,

\begin{equation}
H_{\rm Ising} = -J\sum_{\langle i,j\rangle} \sigma_i \sigma_j, \qquad m = \frac{1}{N}\sum_i \sigma_i,
\end{equation}

which has ferromagnetic order ($|m|\to 1$) below a critical temperature $T_c$ and is disordered
($m\to 0$) above it. If we only have a single snapshot of the spin configuration, at some unknown
temperature, it is easy to see the phase even by eye. We sum the spins and check whether the
result is close to $\pm N$ or close to $0$. Even so, it is a clean and controlled test case for
machine learning. We train the same cat-versus-dog architecture of Section 10.2 on labeled
snapshots below and above $T_c$, where the input is the $N\times N$ spin snapshot and the output is
a one-hot label for ordered or disordered. The classifier then gives a transition that becomes
sharper as the system size grows, where the sweep on the slides goes from $L = 10$ up to $L = 60$,
and this reproduces what we already know analytically.

\textbf{The hard case, the Ising gauge theory.} Now we replace the coupling between pairs with a
\textbf{plaquette} interaction, which is the product of the four spins around each elementary square
of the lattice,

\begin{equation}
H_{\rm IGT} = -J\sum_{p} \prod_{i \in \partial p} \sigma_i,
\end{equation}

where the sum runs over the plaquettes $p$ and the product runs over the four spins on the four
bonds around that plaquette. Note that here the spins live on the \emph{links} of the lattice and
not on its sites. At zero temperature the ground state satisfies $\prod_{i\in\partial p}\sigma_i =
+1$ on \emph{every} plaquette, but this constraint is satisfied by a macroscopic number of different
spin configurations. For instance, if we flip the four spins on the bonds that meet at a single
vertex, every plaquette product stays the same, because each of the four plaquettes that touch this
vertex contains exactly two of these four bonds and every other plaquette contains none of them.
This local gauge transformation is what gives the model its name. At infinite temperature, instead,
plaquettes with product $+1$ and $-1$ appear with equal probability. Both the ordered
configurations, which satisfy the constraint, and the disordered ones can look, one by one, like a
featureless $50/50$ mix of up and down spins. As a result, the naive order parameter (10.9), which
worked perfectly for the Ising model, is \emph{useless} here. The reason is that no local quantity
can distinguish the two regimes, which is the same obstruction that forced sessions 3 and 4 to leave
local order parameters and to use Chern numbers and Zak phases. What (10.10) reproduces, in a simple
classical model, is this feature of those earlier examples. Note that in two dimensions this model
has no true transition and no topological order at finite temperature, and only its ground state at
zero temperature has topological order. On a finite system, however, the low-temperature and
high-temperature regimes are clearly different, and no local quantity can distinguish them, which
is what makes this model a good test for the classifier.

A convolutional neural network, trained on labeled configurations at low $T$ and high $T$ with the
same supervised architecture as before, succeeds where the naive summary statistic fails. In
practice, it learns a nonlocal function of the spin configuration, which plays the role that a
topological invariant would play analytically. We should state one more physical point carefully,
since it is easy to mix up. The two regimes here are separated by a \textbf{size-dependent
crossover} and not by a true phase transition at finite temperature, so there is no sharp $T_c$
that the result converges to as the system grows, unlike the true Ising transition of (10.9). What
makes the machine-learning result useful is that the trained network has only seen one system size
during training, and it still captures this crossover correctly for \emph{other} sizes and
temperatures on which it was never trained. The slides show it trained at a single size and
evaluated from $L = 4$ up to $L = 28$. Figure~\ref{fig:s10:phaseclass} shows the easy and the hard
case next to each other in real space, which is where the difference between them can be seen.

\section{Hamiltonian learning as the inverse of the first step of session 1}

We come at the end to the part of this session that closes the loop in the most explicit way. Let
us go back to session 1, Section 1.4. Every quantum mechanical system is described by the
Schr\"odinger equation, and if we have a Hamiltonian and an initial state we can integrate forward
in time and obtain, in principle, every observable of the system, such as the density, the
magnetization, the response functions and so on. This forward arrow, Hamiltonian $\to$ observable,
is what almost this entire course has been built to compute, one physical setting at a time.

However, this is not the arrow that an experimentalist can use. A real measurement never gives you
the Hamiltonian. It gives you an observable directly, such as a density, a conductivity, an ARPES
spectrum or a neutron-scattering structure factor, and the Hamiltonian is the thing that you do
\emph{not} have and would like to infer. \textbf{Hamiltonian learning} writes this explicitly as the
inverse problem. On the slides the Hamiltonian is written as $H(\lambda_i, w_i)$, where its
dependence is split into two parts. The first part are the physical parameters of interest
$\lambda$, such as magnetic or electric fields, hopping amplitudes and many-body interaction
strengths. The second part is a set of ``hidden,'' or nuisance, variables $w$ that one does
\emph{not} want to fit, such as smaller parameters, disorder realizations, artifacts of the
computational method that generated the training data, and plain randomness. If we write $\mu
\equiv w$ for this vector of hidden variables, the forward direction is the map

\begin{equation}
\mathcal{O} = \mathcal{O}\big[H(\lambda,\mu)\big],
\end{equation}

and Hamiltonian learning asks for the inverse map, $\mathcal{O} \mapsto \lambda$, where we
marginalize over $\mu$ as well as we can instead of trying to fit it. In general this is a
difficult inverse problem, since many different $\lambda$ can be compatible with the same measured
$\mathcal{O}$, and there is little real experimental data to train on. The practical strategy is,
once again, to use theory to compensate for the lack of experimental data. We simulate the
observable $\mathcal{O}$ from many different and \emph{known} Hamiltonians $H(\lambda_n)$ that cover
the range of parameters of physical interest. These are the same forward calculations, such as the
density, the magnetization and the spectroscopy, that we learned to compute directly in the earlier
sessions. Then we train a neural network $\mathcal{N}_\theta$ on this synthetic data to invert
(10.11), and we do this by minimizing

\begin{equation}
\mathcal{L}(\theta) = \sum_n \left\| \mathcal{N}_\theta\big(\mathcal{O}[H(\lambda_n)]\big) - \lambda_n \right\|^2.
\end{equation}

Once the network is trained on simulated pairs, where the answer $\lambda_n$ is known by
construction, the same network is applied to a real experimental observable $\mathcal{O}_{\rm
exp}$. The concrete example of the lecture was a two-dimensional spectroscopy of a quantum magnet.
Then $\hat\lambda = \mathcal{N}_\theta(\mathcal{O}_{\rm exp})$ gives an estimate of the physical
parameters of the Hamiltonian, for instance the first-, second-, and third-neighbor exchange
couplings of that magnet, extracted directly from a measurement for which there is no closed-form
inversion formula at all. Figure~\ref{fig:s10:hamlearning} shows both stages, the synthetic training
set and the use on real data, together with the forward arrow that the two stages invert.

This is the mirror image of the starting point of session 1, and we want to stop for a moment on
this symmetry. In nine sessions we built more and more sophisticated ways to go from a Hamiltonian
to an observable. These are mean-field decoupling, Bloch's theorem, topological invariants, Landau
levels, Nambu spinors, magnon spectra, tensor-network ground states, parton constructions and
response functions. Hamiltonian learning does not leave any of these behind. Instead, it uses the
same forward methods, run many times on synthetic data, as the training set to learn how to run the
process in reverse. In this sense, the method of the course and the final method of the course are
the same method, applied in opposite directions.

\section{Closing summary}

\begin{itemize}
\item A deep neural network is a parametric function that is trained by minimizing a loss function
  with gradient descent, equation (10.1). Every other construction in this session is a specific
  choice of input, output and loss built on top of this one template.
\item \textbf{Neural network quantum states} replace the explicit storage of the $2^L$ coefficients
  of a wavefunction with a network $C_\theta(s)$, equation (10.2), which is trained by using the
  variational energy as the loss function, equations (10.3)-(10.5). NNQS is above matrix product
  states and PEPS in the variational hierarchy, and it imposes the least structure of all the
  ans\"atze of this course. The same ansatz, fitted by maximum likelihood instead of energy
  minimization, solves quantum state tomography with far fewer than $2^L$ measurements.
\item \textbf{Tensor networks}, built from the matrix product state ansatz (10.6) and its
  generalizations to trees, MERA and PEPS, can be used in the reverse direction as
  machine-learning architectures. For image classification on Fashion-MNIST, this reaches 95.38\%
  training accuracy and 88.97\% test accuracy, which is comparable with conventional neural
  networks.
\item \textbf{Density functional theory} is based on the Hohenberg-Kohn functional (10.7) and the
  Kohn-Sham self-consistency loop (10.8). Machine learning enters in two ways. It can learn the
  unknown exchange-correlation part of (10.8), and then the self-consistency loop stays the same, or
  it can learn the whole map from potential to density directly, and then the self-consistency loop
  is removed completely.
\item \textbf{Phase classification} uses one more time the split of this course between local order
  parameters and topological order. The Ising model (10.9) is the easy case, which can be detected
  locally and follows the logic of sessions 1, 5 and 6. The Ising gauge theory (10.10) is the hard
  case, where no local order parameter distinguishes the low-temperature and high-temperature
  regimes, which are separated only by a crossover, and it follows the logic of
  sessions 3 and 4. A trained network succeeds where the naive order parameter fails.
\item \textbf{Hamiltonian learning} treats the inference of a Hamiltonian from measured observables,
  equation (10.11), as the inverse of the first step of session 1. We train a network on synthetic
  forward data, equation (10.12), and apply it to real experimental observables, and in this way we
  close the loop in practice and not only in principle.
\end{itemize}

We started this course by asking how a small number of identical atoms, arranged in a lattice, can
give rise to a phenomenology as rich as the one that we studied in ten sessions. This includes
charge density waves, magnets, superconductors, topological insulators, fractional excitations,
spin liquids and more, and none of it can be seen in a single atom alone. To answer this question we
went through second quantization and mean-field theory, through Bloch's theorem and topological
invariants, through Nambu spinors and magnon spectra, through tensor networks and parton
constructions, and through linear response as a diagnostic for all of them. This session closed
the arc in two ways. First, it showed that a neural network can take the place of the many-body
wavefunction itself. Second, it showed that all the forward methods of the course, with a
Hamiltonian as input and an observable as output, can be run backward to infer the Hamiltonians of
real materials. This is a good place to end the course, not with a final answer, but with a general
method to ask the question again, for the next quantum material that we want to understand.
