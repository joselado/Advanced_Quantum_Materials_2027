\begin{aqmfigure}{fig:s10:template}{The construction that the rest of this session uses again and
again. \textbf{Left.} A deep network is a parametric function $f_\theta$. The architecture, which is
the number of layers and their width, fixes which functions it \emph{can} represent, and the weights
and biases $\theta$ fix which one it \emph{does} represent at a given moment. Here the input is a
small picture and the output is a one-hot label. \textbf{Right.} Training is the loop of (10.1). We
evaluate the output, compare it with the label through a loss, obtain
$\partial\mathcal{L}/\partial\theta$ exactly with backpropagation, take a gradient step and repeat.}
