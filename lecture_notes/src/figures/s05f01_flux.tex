\begin{aqmfigure}{fig:s05:flux}{A drawing of flux quantization. On the left there is a
superconducting ring. Deep in the bulk the Meissner effect has already removed the supercurrent, so
on the dashed contour the gauge-invariant combination $\hbar\nabla\theta-2e\mathbf A$ vanishes and
the phase gradient is locked to the vector potential. On the right, the arrows are the condensate
phase $\theta$ at points of this contour. When we move once around it, the phase must come back to
itself, so it can only wind by an integer number of turns. Together, the two statements give
$\Phi=n\,h/2e$, which means that the flux through the hole is quantized, and the $2$ in the
denominator is the charge $2e$ of a Cooper pair. None of this is a property of a single electron. It
is a macroscopic sample that gives back a ratio of microscopic constants, only because gauge
symmetry is broken.}
