\begin{aqmfigure}{fig:s10:tnml}{Tensor networks used in the reverse direction. \textbf{(a)} The four
geometries that the text names, drawn as tensor diagrams. Every block is a tensor, every rod is an
index that is summed over, and the open legs are the physical indices. The bond dimension $D$ of the
internal lines is what (10.6) calls a free parameter. For a ground-state search these geometries are
not equivalent, since an MPS is easy to optimize and a PEPS is not. However, as flexible functions
of a high-dimensional input with parameters, which is all that a classifier needs, any of them can
be used. \textbf{(b)} Image classification with a tree tensor network. Each pixel becomes a vector
with two components, and their tensor product is a single vector in a $2^N$-dimensional space, which
is the same space where an $N$-spin wavefunction of (10.2) lives. Classification is then a
\emph{linear} map from this space down to two numbers, the red leg, and the tensor network is the
efficient and structured parameterization of such a map that (10.6) already gave us. Note what
changes and what does not change with respect to figure~\ref{fig:s10:template}. The input is still
an array with a categorical label and the output is still one-hot, and only the function between
them is now built from matrices instead of layers of nodes.}
