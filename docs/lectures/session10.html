Session 10. Machine learning quantum materials

Learning outcomes

  • Explain how a neural network is trained by minimizing a loss function
  • Use a neural network as a variational many-body wave function, with the energy as the loss
  • Explain how quantum state tomography gives a wave function from projective measurements
  • Use a tensor network as a classifier for supervised learning
  • Relate the Hohenberg-Kohn theorem to learning the density functional with machine learning
  • Recognize phase classification and Hamiltonian learning as supervised learning on simulated data

Contents

  • Machine learning and its three kinds of task
  • Neural networks and supervised learning
  • Neural-network quantum states
  • Variational states and quantum state tomography
  • The many-body wave function as a matrix product state
  • Supervised learning with tensor networks
  • Density functional theory, Hohenberg-Kohn and Kohn-Sham
  • Machine learning the functional
  • Phase classification in the Ising model and the Ising gauge theory
  • Hamiltonian learning

Simulations shown

  • Neural network classifying Ising snapshots, probability of the ordered phase against T, sharper for bigger L
  • Restricted Boltzmann machine for a 10-site Heisenberg ring, energy going down by gradient descent
  • Tomography of a transverse-field Ising ring from snapshots, fidelity against the number of snapshots
  • Matrix product state of a 16-site Heisenberg chain, error against the bond dimension
  • Tree tensor network telling a bag from a shirt in Fashion-MNIST, accuracy against bond dimension
  • Hubbard chain of 10 sites, exact density against Kohn-Sham, and a learned exchange-correlation functional
  • Ising gauge theory snapshots, a size-dependent crossover captured by a convolutional network
  • Hoppings t1, t2, t3 of a square lattice learned from its density of states, predicted against true
