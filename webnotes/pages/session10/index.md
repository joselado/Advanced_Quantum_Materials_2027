# Machine Learning Quantum Materials {#session-10}

At the end of Session 9 we used linear response as a diagnostic tool, and we applied it to almost every class of system that we built in the course, which are metals, superconductors, topological matter and quantum magnets. That session was a synthesis in a narrow sense, since one formalism was applied to all the systems. In this session we do a synthesis in a much broader sense. We will leave condensed matter for a moment and ask what happens when machine learning meets everything that we built in the last nine sessions, in both directions. In some cases, a machine-learning architecture will be the right tool for a hard many-body problem. In other cases the reverse will be true, and a many-body technique that we already know will be the right architecture for a machine-learning problem. This is also, on purpose, the last session of the course, and before we start we should say clearly that there is one practical difference with all the sessions before. **There is no companion Jupyter notebook for this topic**. The `jupyter-notebooks/` folder stops at `session9.ipynb`, so in these notes there are no "try it in the notebook" boxes. The reason is not that the material is less practical, but that this part of the infrastructure was not built for this session. For this reason, we should study the derivations of this session directly on the page.

The session closes the arc of the course in two ways, and we name both of them before we start. First, we will build neural network quantum states from the beginning. This is the first time that the course meets this idea in full. A neural network takes the place of the exponentially many coefficients of a many-body wavefunction, and it is trained by using the variational principle as a loss function. It has its own place in the hierarchy of variational many-body states, together with matrix product states and projected entangled pair states, and we will use it a second time to reconstruct wavefunctions from a small number of measurements. Second, and this is where the course comes back to its starting point, we will see Hamiltonian learning, which is the inverse of the very first step that this course made. Session 1 started by saying that, if we are given a Hamiltonian, we can integrate the Schrödinger equation forward in time to get observables. The last topic of this session starts from the observables and asks for the Hamiltonian. Ten sessions after we first wrote that forward arrow, we will reverse it.
