# Excitations and Defects in Quantum Materials {#session-9}

In Session 8 we built a small set of new ground states. These were quantum spin liquids described by mean-field spinons, and Kondo lattices, where the local moments are screened by the conduction electrons with the same Abrikosov-fermion construction, so that a metal becomes a heavy-fermion insulator. Up to now every session has followed the same procedure. We take a many-body Hamiltonian, we write it in a controlled or approximate way, and we read the resulting ground state. In this session we use all of these methods in a different way. Instead of building one more ground state, we will *probe* the ground states that we already have. The idea is easy to state. We take a quantum material, which can be a metal, a superconductor, a topological insulator or a quantum magnet, we disturb it a little, and we look at how it responds. The response itself is computed only from the undisturbed ground state, and it tells us a lot about what that ground state is. We will use this one idea, linear response, as a probe of almost every class of systems that we have built in the course so far. These are ordinary metals, the superconductors of session 5, the topological matter of sessions 3 and 4, and the quantum magnets of session 8. In each case we will see that the response function works as a diagnostic, and it gives us Fermi surfaces, superconducting pairing symmetries, topological invariants and spin gaps, all from the same formalism. We will also see that the Stoner criterion for itinerant magnetism follows directly from the same language of response functions. This connects again to the magnetism of session 1 and session 6, but now we see magnetism as an *instability* of the paramagnetic response and not as a mean-field ansatz for the ground state that we impose by hand. In this sense, this is the diagnostic and synthesis session of the course, which gives a new way to look at everything that we have built.
