## Landau levels and chiral edge states in the quantum Hall state {#sec-3-6 number="3.6"}

The Chern number appears in its simplest form in the quantum Hall state itself, which is a two-dimensional electron gas in a strong perpendicular magnetic field. The resulting band structure is the flat-band type of dispersion from session 2, which is a set of Landau levels without dispersion, and each Landau level has Chern number $+1$. If we fill the first Landau level, the total Chern number is $C=1$. If we fill the first two, we get $C=2$, and so on, so that $\sigma_{xy} = C\, e^2/h$ goes through successive integer plateaus as the chemical potential goes up through successive Landau levels. This is the integer quantum Hall effect, and in session 4 we will work out its full phenomenology, including the fractional case. In this session we only need to count the Chern numbers.

This raises a puzzle. We have an insulator, with a gap between Landau levels, but $\sigma_{xy}$ is a *conductivity*, which means that some electron has to move somewhere. The answer is that any real sample has an edge, and at this edge the bulk gap closes. Gapless edge states appear, and they carry the current that [(3.4)](#eq-3-4) predicts. These edge states have another key property, which is that on a given edge the states propagate in only *one* direction. The top edge of a sample carries current in one direction only, and the bottom edge carries it in the opposite direction only. A mode that propagates in a single direction is called **chiral**, and chirality is what protects the quantum Hall state against disorder. An electron in a chiral edge mode cannot backscatter, since there is no state that propagates in the opposite direction at the same edge and the same energy. Without a backscattering channel there is no resistance in this channel. Figure [3.1](#fig:s03:chiraledge) shows both parts of this picture, which are the closed bulk orbits that carry no current and the skipping orbits that carry all of it, and it also shows what happens when an impurity is put in their way.

They skip along the edge, and for a given direction of $B$ they skip in one direction only, which is opposite on the two edges. Let us look at a concrete model. We take a tight-binding square lattice with a perpendicular magnetic field and cut it into a ribbon of finite width, which has translational invariance along the ribbon but is finite across it. When we diagonalize this ribbon, we find the structure described above. There are flat bulk bands similar to Landau levels, and there are dispersive edge branches that cross the gap, with one branch confined to each edge and propagating in only one direction. If we look at the low-energy region close to zero energy, the spacing between the flat bands approaches the equal spacing of a continuum two-dimensional electron gas in a magnetic field, so the tight-binding model reproduces the standard Landau problem in the appropriate limit. This computed band structure, with the bulk flat bands in green and the two edge branches that propagate in opposite directions, is shown on the slides but was only described qualitatively in the lecture.
