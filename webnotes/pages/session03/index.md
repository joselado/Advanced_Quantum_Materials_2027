# Topological Band Structure Theory {#session-3}

In the last session we ended with the most important feature of the honeycomb lattice. Close to the corners of its Brillouin zone, the tight-binding band structure is not parabolic anymore and becomes linear, which is the Dirac cone. This is one of the three types of dispersion that we chose to organize the rest of the course, which are parabolic, Dirac and flat. We also saw that this is not only a convenient theoretical picture, since ARPES measures this linear dispersion directly in real graphene. The question for this whole session is what happens if we open a gap at this Dirac point. A Dirac cone with a gap turns a metal into an insulator, but this insulator is not always an ordinary one. Depending on *how* the gap opens, the insulator can have a hidden invariant, which is called a topological invariant. This invariant does not appear anywhere in the bulk spectrum, but it forces the material to have conducting states at its edge, and no local disorder can remove these states. To reach this statement in an exact way we need several steps. First, we need linear response theory as a tool. Then we need the Hall conductivity, which is the observable where the invariant first appears, and the Chern number, which is the invariant itself. Finally, we need the general bulk-boundary correspondence, which connects the invariant to the physics of the edge. We will build all of this with the quantum Hall state, which is the simplest example. Then we will use the same tools for a purely one-dimensional model, the SSH chain. At the end, in Section [3.10](#sec-3-10), we will come back to the Dirac cone of the honeycomb lattice, open a gap in it, and see a real Chern insulator appear without any magnetic field.
