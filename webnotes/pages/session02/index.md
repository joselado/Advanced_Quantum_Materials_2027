# Symmetries, Tight-Binding Band Structure Theory, and Effective Models {#session-2}

In the last session we introduced second quantization and used it in practice. Mean-field theory turned an interacting, quartic Hamiltonian into an effective single-particle one, and we saw that the same method gives a charge density wave, a magnet and a superconductor, one for each of the three symmetries that a many-body ground state can spontaneously break. We also spent some time on what this breaking means. We used the example of the bread on the table, where there is a set of solutions with the same energy and no single one of them has the full symmetry. We saw that this picture only becomes sharp in the thermodynamic limit, we discussed the ferroelectric as a fourth example next to magnets and superconductors, and we compared all this with topological order, which can distinguish two materials that have the same broken symmetries. This is a complete topic by itself, and in this session we will not repeat any of it.

In this session we ask a different question, which is about the structure of the problem. Once the interactions are included in a mean-field, single-particle Hamiltonian, how do we solve it? For a few sites we can diagonalize a matrix directly, but a real material has of order $10^{23}$ sites, and no computer can diagonalize a matrix of this size. The answer is again symmetry, but now it has a different role than in the last session. We do not use it to classify which order a ground state breaks, and instead we use it to simplify the diagonalization. When the ground state of a Hamiltonian *shares* the symmetry of the Hamiltonian, the symmetry is not only a classification tool, and it becomes a real shortcut. It turns an infinite-dimensional problem that we cannot solve into infinitely many finite-dimensional problems that are easy to solve. For a periodic system, this shortcut is called Bloch's theorem. At the end of this session we will have used it to derive several real band structures, including the Dirac cone of graphene, which the topology lecture that comes right after this one will take and gap open.
