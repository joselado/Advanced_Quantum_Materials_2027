# Second Quantization, Mean-Field, and Spontaneous Symmetry Breaking {#session-1}

This is the first session of the course, so we start with the question that organizes the whole course. How do we go from a single atom, which is an object that we understand rather well, to a *quantum material*, where electrons that move together give rise to phenomena that no single atom can show? To answer this question we need a new mathematical language, which is second quantization, and a first tool to use it, which is mean-field theory. In this session we will use this tool three times, and we will obtain a charge density wave, a magnet and a superconductor from the same starting Hamiltonian, only by changing the sign and the geometry of one interaction term. These three cases are broken translational symmetry, broken time-reversal symmetry and broken gauge symmetry, and they are the structure on which the rest of the course is built, so it is useful to keep them in mind from the start. Note also that this session is the *only* place in the course where we discuss the general logic of spontaneous symmetry breaking in detail. The next session goes directly to symmetry and band structure and does not come back to it, and magnetism and superconductivity are discussed in full only much later, in sessions 6 and 5 respectively. For this reason, what we build here has to carry these concepts on its own.
